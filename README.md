# Penumbra 半影 · Beta 0.1

Windows x64 桌面暗角工具。设置界面使用 WinUI 3 / Windows App SDK，常驻后台为独立 C++ Win32 程序。构建目标为 Windows 10 2004（19041）及以上；本机验证结果见 TEST-REPORT.md。

## 使用

1. 完整解压发行包，打开 `dist\Penumbra-beta-0.1-r3`，运行顶层的 `Penumbra.exe`。不要单独移动 EXE，必须保留旁边的 `app` 文件夹；“关于”显示 Beta 0.1，r3 为动画与响应修订包。
2. 打开设置时会自动在后台刷新主屏预览；也可点击“刷新壁纸”。Wallpaper Engine 动态壁纸取当前一帧，不最小化应用或切换前台窗口。
3. 调整强度、中心半径、羽化、长宽比、中心位置、色调和屏幕范围，左侧预览随参数变化更新；点击“应用到桌面”会再刷新一次壁纸并应用当前参数。色调选项为碳黑、墨蓝、暖黑。
4. 关闭设置窗口后，由原生后台保留效果；托盘提供打开设置、暂停、重新挂接及退出。
5. “恢复桌面”退出后台。图标默认不受暗角影响；勾选“压暗桌面图标”可让暗角同时覆盖图标。登录启动需主动开启，并点击应用保存；默认不开启。

强度 0% 为透明；半径与中心使用每屏归一化坐标。所有屏幕模式为每屏独立暗角。预览只显示主屏快照，壁纸切换后需重新读取。

## 焦点自动切换（可选）

开启右侧“仅其他应用聚焦时启用暗角”，点击“应用到桌面”后生效。此项默认关闭，旧配置继续保持暗角常开。

- 桌面或桌面图标获得焦点：暗角围绕所设中心向外舒展，后半段逐渐透明，结束后销毁暗角窗口。
- 普通应用获得焦点（包括资源管理器文件窗口、Penumbra 设置窗口）：反向淡入，恢复设定的暗角范围和强度。
- 任务栏、托盘、开始菜单、搜索和临时菜单保持之前状态，避免短暂的系统焦点造成闪烁。两个普通应用之间切换不会重新播放动画。
- 完整过渡约 360 毫秒，使用快速起步、柔和收尾的三次缓动；中途反向从当前进度衔接。此项为用户主动开启的暗角效果，即使 Windows 动画效果关闭也会播放，不修改系统设置。
- 缩放仅作用于暗角图案，图标保护遮罩保持原位。左侧预览仍展示最终参数效果，不跟随系统焦点自动变成空白。

焦点变化通过 Windows 事件通知立即触发，不用高频轮询，也不再额外等待 45 毫秒。动画使用短时可等待定时器，避免普通低优先级窗口计时消息被淹没；图标遮罩更新避开动画期间。结束后关闭定时器、释放纹理与 CPU 帧位图，隐藏时同时销毁分层窗口以释放其表面。进程使用正常调度优先级以及时接收焦点事件；静止时仍阻塞休眠，只有原来的 10 秒恢复检查，不保留 Direct3D 设备或持续捕获壁纸。

已知问题：完全淡出后再次切回应用，淡入动画有时会跳过、瞬间出现；淡出中途反向恢复相对顺滑。此问题尚未完全修复，r3 按当前可测试状态发布。

预览框外右下角显示“Wallpaper Engine 活动状态”：检测到当前登录会话的 `wallpaper32.exe` 或 `wallpaper64.exe` 时为绿点，未检测到或无法读取时为灰点。悬停可查看文字状态。打开设置、重新激活窗口或刷新壁纸时检测；设置窗口可见且未最小化时每 5 秒更新，关闭窗口后不再检测。此状态仅表示进程是否运行，不代表动态壁纸正在播放或桌面暗角已经应用成功。

左侧登录启动开关下方直接显示“关于”：圆形作者头像、冷茶Reicha、当前版本 Beta 0.1，以及白色的 bilibili / GitHub 图标链接，无需打开弹窗。头像来自作者提供的本地图片，不联网读取。点击图标后在默认浏览器中打开作者主页，不内嵌网页，也不会在启动时请求这些网站。应用显示名称已从 VignFinder 取景器更改为 Penumbra 半影；继续沿用原配置目录和后台文件名，保留用户设置。

## 发行目录

```text
Penumbra-beta-0.1-r3/
  Penumbra.exe   启动入口（启动界面后立即退出，不常驻）
  README.md      使用说明
  app/           程序本体、后台、全部 DLL、语言和头像资源
  docs/          验证记录和第三方许可
```

语言资源保留运行库要求的相对路径，统一收纳在 `app` 内，不手动改名或打散 DLL。后台的托盘设置入口与登录启动仍指向 `app` 内的程序；移动整个发行文件夹后，应重新应用登录启动选项。

体积优化使用 WinUI 组件包代替全量 Windows App SDK 包，不分发本软件未使用的 ML、AI、Widgets 等组件；启用 .NET 部分裁剪并关闭调试符号。仍为自包含便携版，不要求另装 .NET 或 Windows App Runtime。本次没有将 DLL 压缩为运行时自解压包，避免额外解压缓存。

## 预览与窗口外观

窗口支持拖动边框调整宽高、最大化和还原；最小尺寸为 480×320 个有效像素，并随当前屏幕 DPI 换算。宽度不足 920 个有效像素时，参数区自动移到预览下方；空间不足时可纵向滚动，底部操作按钮保持可见。预览随宽度保持壁纸比例，窗口缩放不触发壁纸捕获，也不重新计算暗角像素。

预览在滑块拖动期间节流更新，避免为每个指针事件重新分配位图。预览图按主屏比例铺满，不留两侧底色，不叠加壁纸名称或时间标签。右侧参数区无外围描边，滑块标题与对应控件成组排列。Windows 11 使用 WinUI 3 Mica 系统背景；旧版 Windows 使用系统提供的回退外观。

刷新使用 Windows Graphics Capture 读取 Explorer 桌面宿主，普通应用遮挡桌面时也可获取壁纸。只创建短暂的一帧捕获会话，获取后关闭 Direct3D 设备与帧池；没有持续捕获。系统可能短暂显示捕获提示边框。壁纸自身暂停时读取最后可用画面；锁屏、桌面不可用或捕获超时会提示失败，并保留上次成功的预览。

## 桌面效果

原先挂在 Explorer 内的分层子窗口，在本机 Wallpaper Engine 下没有显示。本版改为无所有者、非置顶、点击穿透的顶层透明窗口，并把它放在桌面上方、普通应用下方。

这类窗口也处于图标上方，因此本版从 Explorer 单独读取图标与文字的绘制结果，按实际像素生成透明遮罩，让图标保留亮度，避免整块矩形区域露出明亮壁纸。图标创建、移动、重命名、选择等事件经过 350 毫秒合并后更新遮罩；结果相同则不重绘。预览也使用图标遮罩。

每次应用会先请求旧后台正常退出，再启动同目录新版，避免旧程序继续处理新版设置。

## 资源占用

- 后台不加载 .NET、WinUI、WebView2 或 Direct3D，静止时无逐帧绘制、持续壁纸抓取或忙循环。
- 参数、屏幕布局或图标遮罩变化时生成完整分辨率的预乘 BGRA 位图，通过 `UpdateLayeredWindow` 提交后释放临时 CPU 位图和 GDI 资源。
- 图标遮罩常驻缓存每像素 1 位；2880×1620 约 0.56 MiB。读取图标和提交表面时有临时位图成本。
- 焦点动画期间，每屏临时保留一张完整尺寸 BGRA 帧和一张最长边不超过 1024 的暗角纹理；2880×1620 的这两张图共约 20 MiB，结束后释放。焦点模式保留动画最终提交的全屏帧，不在终点重新计算整屏像素而阻塞下一次切换；常开模式仍按原分辨率计算。
- 前景、最小化及桌面层级事件触发合并后的层级调整；每 10 秒执行一次恢复检查，静止时不重绘。其他应用的普通对象事件会被过滤。
- Windows 合成器另持有每屏透明表面；3840×2160 的 32 位表面约 31.6 MiB，不能用后台私有内存代表全部成本。
- 发行包含自包含 UI 运行库，磁盘大小与常驻内存是两回事。关闭设置窗口可释放 UI 进程。

## 兼容范围

已在本机运行 Wallpaper Engine 时实际验证壁纸变暗与图标亮度保护。Explorer 桌面结构、壁纸渲染模式及 Windows 版本会影响结果；未验证所有场景、视频、网页壁纸和混合 DPI 多屏。具体测试及限制见 TEST-REPORT.md。

桌面宿主不可用或首次图标遮罩读取失败时，不显示暗角并报告状态。Explorer 重启后会低频尝试恢复，也可从托盘“重新挂接桌面”。图标变化后存在短暂更新延迟。

## 文件与隐私

配置与状态：`%LOCALAPPDATA%\Nocturne\settings.ini` 和 `status.txt`。异常时可能写入 `ui-error.txt` / `startup-error.txt`。

程序不会主动联网、不修改壁纸文件；只有主动点击作者主页链接才会交给浏览器打开。桌面预览在打开设置、点击刷新或应用时读取，包含图标，只保留在设置进程内存。捕获目标为桌面窗口树，已有的独立暗角表面与普通应用窗口不属于该窗口树；刷新期间不隐藏暗角、不模拟快捷键、不改变应用窗口状态。

登录启动使用当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\Nocturne`。移动发行目录后需重新应用此选项；取消勾选并应用可移除启动项，关闭暗角本身不取消登录启动。退出后台后透明表面随进程释放。

## 构建

需要 .NET 8 SDK、可访问 NuGet 的网络、Windows x64 和 llvm-mingw UCRT x64 工具链。本次使用 20261020 版 llvm-mingw。

```powershell
./build.ps1 -Toolchain 'D:\Tools\llvm-mingw-20261020-ucrt-x86_64' -OutputDirectory 'dist\Penumbra-beta-0.1-r3'
# 原生动画、图标保护、快速反向和资源释放测试（在屏幕外运行）
./tests/run.ps1 -Toolchain 'D:\Tools\llvm-mingw-20261020-ucrt-x86_64'
```

产物为 `dist\Penumbra-beta-0.1-r3` 完整目录，入口为顶层的 `Penumbra.exe`。这是未签名的便携构建。`app\Nocturne.Renderer.exe --self-test` 仅验证暗角和动画数学性质，不能替代桌面视觉验收。需要排查时，可用 `--trace-animation` 单次启动后台，在配置目录生成数字帧日志与焦点诊断；默认关闭，不记录屏幕图像。GitHub 与 bilibili 图标许可见 `docs\THIRD-PARTY-NOTICES.txt`。
