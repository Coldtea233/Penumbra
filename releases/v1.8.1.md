## 新增

- 版本号右侧增加灰色下划线“检查更新”，软件内版本号不再显示 `v` 前缀。
- 每次启动设置界面时异步检查 GitHub 最新正式 Release；发现新版后可点击查看发布页，不自动下载安装。
- 手动检查提供无更新、网络错误和重试反馈；GitHub API 受限时通过官方最新发布链接进行轻量回退检查，不需要账号或 Token。

## 说明

- 保留原有暗角、模糊、降饱和度效果和后台性能优化，更新检查仅在设置进程内运行，没有后台轮询。
- 目前尚未直接检测 Wallpaper Engine 的焦点暂停设置或实际暂停状态；现有全屏遮挡休眠不等于此功能。
- 支持覆盖安装并保留配置。更新前请关闭设置窗口，并从托盘退出旧版后台。
